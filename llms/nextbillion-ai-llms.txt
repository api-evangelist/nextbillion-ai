# NextBillion.ai

> NextBillion.ai provides enterprise mapping, routing, navigation, route optimization, dispatch, and location intelligence technology for logistics, fleet management, delivery, mobility, and other location-intensive applications.

NextBillion.ai provides APIs, SDKs, map data, and operational applications that help businesses build location-aware products and optimize complex transportation workflows.

The platform is designed for organizations managing large fleets, high stop volumes, multi-stop deliveries, field-service operations, on-demand mobility, and routing problems with real-world constraints.

Key capabilities include route optimization, directions, distance and ETA calculation, navigation, geocoding, places, fleet tracking, dispatch, driver assignment, geofencing, route reconstruction, maps, and location data.

NextBillion.ai also provides tools for building AI and agent-based location applications, including the NextBillion.ai MCP Server.

## Product

### Route Optimization API

- [Route Optimization API](https://docs.nextbillion.ai/optimization/route-optimization-api): Programmatic route optimization for single- and multi-vehicle routing problems.
- The API can model real-world routing scenarios using vehicles, jobs, locations, shipments, relations, objectives, and routing constraints.
- Supported planning scenarios include vehicle capacity, time windows, driver shifts, service times, vehicle availability, pickup and delivery, route preferences, and other operational constraints.
- The API supports retrieving optimized solutions and re-optimizing existing solutions when the underlying plan or conditions change.
- The optimizer can use traffic conditions when generating solutions and supports customized travel costs and cost matrices.

### Route Planner / Route Optimization Software

- [Route Optimization Software](https://nextbillion.ai/route-optimization-software): Web-based route planning and optimization application for operations teams.
- Designed for users who need to plan and optimize multi-stop routes without building their own optimization infrastructure.
- Supports complex planning requirements such as time windows, service times, vehicle capacities, depots, driver shifts, priorities, and operational constraints.
- Provides visual route planning and optimization before dispatch.
- Relevant for delivery operations, field service, logistics, fleet management, and other multi-stop routing workflows.

### Routing APIs

NextBillion.ai provides routing APIs for applications that need travel-time, distance, directions, and route information.

- [Directions API](https://docs.nextbillion.ai/routing/directions-api): Calculates routes between locations with configurable routing preferences.
- [Distance Matrix API](https://docs.nextbillion.ai/routing/distance-matrix-api/synchronous): Calculates distances and ETAs between multiple origins and destinations.
- [Navigation API](https://docs.nextbillion.ai/routing/navigation-api): Provides navigation routes and turn-by-turn instructions.
- [Snap to Roads API](https://docs.nextbillion.ai/routing/get-started): Matches location traces to the road network.
- [Isochrone API](https://docs.nextbillion.ai/routing/get-started): Determines areas reachable within a specified travel time or distance.
- [Hours of Service API](https://docs.nextbillion.ai/routing/get-started): Supports HOS-aware scheduling and route planning.
- [Route Report API](https://docs.nextbillion.ai/routing/get-started): Provides trip and route reporting capabilities.
- [Batch Routing API](https://docs.nextbillion.ai/routing/get-started): Supports processing multiple routing requests.

### Navigation
